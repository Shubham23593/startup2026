# DeadlineHub AI - Never Miss a Deadline Again.

Premium React Native App - All-in-One Productivity

## Features - A to Z Working
- ✅ Splash + Onboarding + Lottie
- ✅ Firebase Auth - Google, Email, Forgot Password
- ✅ Home Dashboard - Greeting, Countdown, Stats, Quick Actions
- ✅ Event Manager - Unlimited events, Categories (Hackathon, Assignment, Internship, Interview, etc), Priority, Pin, Favorite, Archive
- ✅ Live Notification - Works when app closed, phone locked, background - Notifee + FCM + Boot Restore
- ✅ Calendar - Monthly/Weekly/Agenda, Color coded
- ✅ Todo Manager - Subtasks, Priority, Tags, Filters
- ✅ Notes - Rich Text, Checklist, Folders, Pinned
- ✅ Document Vault - PDF/DOCX/PPT/Images, Preview, Offline Download, Cloud Sync
- ✅ Countdown - Days/Hours/Minutes animated
- ✅ Hackathon Tracker - Registration -> Winner flow
- ✅ Assignment Tracker - Subject, Professor, Marks
- ✅ Internship Tracker - Applied -> Offer flow
- ✅ Goals, Study Planner, Search, Filters, Statistics with Charts
- ✅ Friends - Share Events
- ✅ AI - Screenshot Import, Clash Detection, PDF Summary, OCR
- ✅ Settings - Dark/Light, Backup
- ✅ Offline Support - WatermelonDB + Auto Sync
- ✅ Premium UI - Material 3, Gradients, Glassmorphism, Rounded Cards

## Tech Stack - Free Without Limit
- React Native 0.73 + TypeScript
- React Navigation + Paper Material 3 + Reanimated + Lottie + Linear Gradient + Blur
- Firebase Auth + Firestore + Storage + FCM
- WatermelonDB (SQLite) for offline - Unlimited free
- Notifee for reliable notifications
- Cloudinary Free 25GB for documents (Firebase 1GB se 25x zyada)
- Gemini API Free for AI

## Backend & DB
- **Local DB:** WatermelonDB - Unlimited, offline-first
- **Cloud DB:** Supabase Free (500MB) + Firestore backup
- **Storage:** Cloudinary Free 25GB
- **For Truly Unlimited Free:** PocketBase on Oracle Cloud Always Free (2 VM, 200GB free forever)

## How to Run - 0 Rs
```bash
npm install
npx react-native run-android
```
Add google-services.json for Firebase
Add Gemini API key in src/services/aiService.ts

## Offline?
Yes 100% offline chalega - Events, Tasks, Notes, Countdown, Calendar, Documents (downloaded). Notification bhi offline bajega kyuki Notifee local alarm hai.

Built with premium Material Design 3, dark/light mode, skeleton loading, swipe gestures, pull to refresh.
